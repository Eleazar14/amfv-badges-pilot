Tipo de evidencia: Página descriptiva para validar el flujo técnico de constancias digitales.

Esta página es una prueba personal de Eleazar. No constituye una constancia oficial emitida por AMFV.

Descripción de la prueba

Esta página fue creada para practicar el flujo completo de generación, publicación y envío de constancias digitales verificables antes de ejecutar el proceso institucional con AMFV.

Elementos que se validarán

  • Publicación de insignia digital.
  • Publicación de BadgeClass JSON.
  • Publicación de evidence HTML.
  • Generación de assertion JSON individual.
  • Generación de página HTML individual de constancia digital.
  • Generación de archivo output_mailmerge.csv.
  • Funcionamiento de URL de PDF de prueba.
  • Envío de correo con Apps Script usando Gmail personal.

Criterio general de esta prueba

La insignia se utiliza únicamente para validar el proceso técnico. No acredita participación oficial, asistencia real ni emisión institucional.

La validación individual de esta prueba se realiza mediante la página de credencial generada y su assertion asociada.
